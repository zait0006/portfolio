# Alaa Zaitounah — Portfolio

A responsive portfolio website for UX/UI, branding and front-end work.

## Files
- `index.html` — main website
- `styles.css` — styling and responsive layout
- `script.js` — small JavaScript enhancements
- `project-image-1.png` — Luxe Glow project image
- `project-image-2.png` — Tiny Treasures project image

## Publish with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will generate a URL similar to:
   `https://YOUR-USERNAME.github.io/portfolio/`
